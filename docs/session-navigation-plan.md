# 세션 탐색 구현 기록

현재 세션 탐색 기능은 상태 필터, 정렬, 즐겨찾기, 상세 보기로 구성된다. 사용법은 [한국어 README](../README.ko.md), 동작 계약은 [UI 문서](ui.md), 검증 방법은 [테스트 가이드](testing.md)를 기준으로 한다.

`f`는 전체·실행 중·중지됨 필터를 전환하고, `o`는 이름순·실행 중 우선 정렬을 전환한다. 검색과 상태 필터를 함께 적용하며 갱신 후에도 선택한 세션 이름을 유지한다.

`p`는 즐겨찾기를 저장하고 목록 위에 모은다. 별 표시는 이모지 표시 지정자를 포함하며, 실제 모양은 터미널과 폰트에 따라 달라진다. 저장은 파일 잠금과 원자적 교체를 사용하며 다른 인스턴스의 즐겨찾기 변경을 보존한다.

`i`는 세션 상태, 기본 세션·즐겨찾기 여부, 전체 세션 상태 디렉터리와 소켓 경로를 보여준다. 상세 보기는 스크롤과 크기 변경을 지원하고, 세션이 사라지거나 갱신이 실패하면 안내한다.

세션 생성은 기존 `n`·`N` 흐름을 사용한다. 중지된 세션의 목록 접속은 기본 차단하고 `--allow-stopped-attach` 또는 `HERDRCTX_ALLOW_STOPPED_ATTACH=1`로 허용한다.

검증에는 Go 기본 검사 4종과 `make test-integration`을 사용한다. 통합 테스트도 모두 Go이며 탐색 PTY, 실제 Herdr 수명주기, 설치, 중첩 실행 차단과 플러그인 등록을 포함한다. 개별 실행의 결과는 `dist/integration`에 기록하며, 로컬 통과 결과를 원격 CI 통과로 간주하지 않는다.
